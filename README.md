## 출입 관리 시스템 ##

## 프로젝트 목적 ##
직원의 출입 기록을 기반으로 출근, 외출, 복귀, 퇴근 등의 상태를 관리하고,
관리자가 이를 조회 및 수정할 수 있는 출입 관리 시스템을 구현한다.

## 주요 기능 ##
기능                설명                   
출입 기록 저장      출입 기록 기반 상태 변경 처리    
상태 관리           출근, 외출, 복귀, 퇴근 상태 관리 
점심시간 처리       점심 외출 및 복귀 처리        
조퇴 처리           조퇴 상태 저장             
근태 조회           직원별 출입 기록 조회         
근태 수정           관리자 수정 기능            
수정 로그 관리      수정 이력 저장 및 조회        

## 시스템 흐름 ##
출입 기록 발생
       ↓
직원 정보 확인
       ↓
현재 상태 조회
       ↓
상태 변경 처리
       ↓
출입 기록 저장

## 관리자 처리 흐름 ##
관리자 조회
      ↓
근태 기록 확인
      ↓
기록 수정
      ↓
수정 로그 저장

## 근무 상태 ##
상태           설명   
WORKING       근무 중 
OUTING        외출 중 
LUNCH         점심시간 
EARLY_LEAVE   조퇴   
OFF_WORK      퇴근   


## API 설계 ## 
Method          설명          
POST            출입 기록 처리    
POST            외출 처리       
POST            복귀 처리      
POST            조퇴 처리       
GET             전체 출입 기록 조회 
PATCH           출입 기록 수정    
GET             수정 로그 조회    


## 예외 처리 ##
- 중복 출근 기록              =     중복 저장 방지 
- 출근 전 외출 처리           =     오류 반환
- 외출 중 중복 외출           =     처리 제한
- 퇴근 후 재출입              =     처리 제한 
- 잘못된 시간 수정            =     수정 제한 

## 프로젝트 방향 ## 
- 본 프로젝트는 실제 출입 인증 기능 구현보다는
  출입 기록 데이터를 기반으로 직원의 출입 상태를 관리하고,
  근태 데이터를 처리하는 기능 구현에 중점을 둔다.
