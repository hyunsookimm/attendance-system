## 출입 관리 시스템 ##

## 프로젝트 목적 ##
직원의 출입 기록을 기반으로 출근, 외출, 복귀, 퇴근 등의 상태를 관리하고,
관리자가 이를 조회 및 수정할 수 있는 출입 관리 시스템을 구현한다.

## 주요 기능 ##
기능              설명                          
출입 기록 저장     출입 이벤트 발생 시 기록 저장            
상태 관리          출근, 외출, 복귀, 점심, 조퇴, 퇴근 상태 관리 
근태 조회          직원별 출입 기록 및 상태 조회            
근태 수정          관리자 출입 기록 수정 기능              
수정 로그 관리     수정 이력 저장 및 조회                
예외 상황 처리     비정상 출입 흐름 제한                 
       

## 시스템 흐름 ##
출입 기록 발생
       ↓
직원 정보 확인
       ↓
현재 상태 조회
       ↓
상태 변경 처리
       ↓
출입 기록 저장

## 관리자 처리 흐름 ##
관리자 조회
      ↓
근태 기록 확인
      ↓
기록 수정
      ↓
수정 로그 저장

## 근무 상태 ##
상태           설명   
WORKING       근무 중 
OUTING        외출 중 
LUNCH         점심시간 
EARLY_LEAVE   조퇴   
OFF_WORK      퇴근   


## API 설계 ## 
Method          설명          
POST            출입 기록 처리    
POST            외출 처리       
POST            복귀 처리      
POST            점심 처리
POST            조퇴 처리       
GET             전체 출입 기록 조회 
GET             직원별 출입 기록 조회 
PATCH           출입 기록 수정    
GET             수정 로그 조회    

## 데이터 구조 설계 ##
- 직원 테이블
id              =        직원 번호
name            =        직원 이름
department      =        부서
employee_number =        사번

- 출입 기록 테이블
id              =        기록 번호
employee_id     =        직원 번호
action_type     =        출입 행동 종류
status          =        현재 상태
recorded_at     =        기록 시간

- 수정 로그 테이블
id              =        로그 번호
attendacne_id   =        수정 대상
before_status   =        수정 전 상태
after_status    =        수정 후 상태
modified_at     =        수정 시간 


## 예외 처리 ##
- 중복 출근 기록                  =     중복 저장 방지 
- 출근 전 외출 처리               =     오류 반환
- 외출 중 중복 외출               =     처리 제한
- 퇴근 후 재출입                  =     처리 제한 
- 잘못된 시간 수정                =     수정 제한 
- 퇴근 기록 누락 후 다음날 출입    =     자동 종료 또는 관리자 확인 처리 

## 프로젝트 방향 ## 
- 본 프로젝트는 실제 출입 인증 기능 구현보다는
  출입 기록 데이터를 기반으로 직원의 출입 상태를 관리하고,
  근태 데이터를 처리하는 기능 구현에 중점을 둔다.
